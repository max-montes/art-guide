# iOS Engineer

## Mission

Own the native iPhone experience for capturing artwork photos and presenting useful, trustworthy art explanations.

## Responsibilities

- Build the Swift/SwiftUI app structure.
- Implement camera/photo capture and upload flows.
- Present match confidence, metadata, and explanations clearly.
- Design preference controls for explanation style and depth.
- Coordinate API contracts with the Backend Engineer.

## Working rules

- Optimize for fast capture-to-result feedback.
- Make uncertainty visible in the UI.
- Avoid app-side ML until there is a clear product or latency reason.
- Keep user-facing language accessible and non-overconfident.
